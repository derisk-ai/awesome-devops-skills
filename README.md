## 🤖 Auto Collection Process

This project automatically scans GitHub every hour to discover new DevOps-related Skills and MCP Servers.

### Collection Criteria

- ⭐ Stars > 5 (new projects) or > 50 (mature projects)
- 🏷️ Tags include: devops, cloud, kubernetes, docker, terraform, mcp, skill, automation
- 📅 Updated within the last 6 months
- 📝 Clear README and documentation

### Search Strategy

```
Keywords:
- devops skill / automation
- kubernetes tool / docker automation
- cicd pipeline / terraform module
- mcp server / ai agent devops
- infrastructure as code / platform engineering
- observability tool / cloud native tool
```

### Current Status

| Metric | Value |
|--------|-------|
| 📊 Total Repos | 46 |
| 🕐 Last Scan | 2026-02-26 23:38 CST |
| 🔄 Frequency | Every hour |
| 🔧 Script | `collect.sh` |

### Technical Stack

- Pure Bash implementation (no external dependencies)
- GitHub Search API v3
- GitHub Token support (increases rate limit from 60 to 5000 requests/hour)

### Workflow

1. Run search queries against GitHub API
2. Filter repositories by keywords and stars
3. Fetch detailed repository information
4. Categorize by tags and content
5. **Create new branch** for updates
6. Submit changes via Pull Request

### Configuration

To increase GitHub API rate limits, create a `.github-token` file:
```bash
echo "ghp_xxxxxxxxxxxx" > .github-token
```
