## 🤖 自动收集流程

本项目通过自动化脚本每天扫描多个来源，发现新的DevOps相关Skills和MCP Servers。

### 数据来源

| 来源 | 类型 | 更新频率 |
|------|------|----------|
| GitHub | API搜索 | 每天一次 |
| ClawHub | Skill Registry | 每天一次 |
| Other Registries | 待定 | 每天一次 |

### 收集标准

- ⭐ Stars > 5 (新项目) 或 > 50 (成熟项目)
- 🏷️ 标签包含: devops, cloud, kubernetes, docker, terraform, mcp, skill, automation
- 📅 最近6个月内有更新
- 📝 有清晰的README和文档
